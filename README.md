# 📌 Project Overview

This project is a complete Heart Disease Prediction System built using:

- 🧠 Machine Learning
- 📊 Data Visualization
- ⚡ Streamlit Dashboard
- 🔬 Clinical Risk Prediction
- 🎨 Advanced Cyberpunk UI Design

The application allows users to:

✅ Upload patient datasets  
✅ Train multiple machine learning models  
✅ Compare model performance  
✅ Predict heart disease risk for individual patients  
✅ Analyze feature importance  
✅ Visualize correlations and medical insights
